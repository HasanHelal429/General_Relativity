# General Relativity

Simulations of general-relativistic effects, built up project by project.

## Projects

- [`Schwarzschild_Raytracer/`](Schwarzschild_Raytracer/) — a raytracer through the Schwarzschild spacetime of a static, non-rotating black hole. Bends light along null geodesics (instead of straight lines) to render gravitational lensing, the photon sphere, the black-hole shadow, and a lensed accretion disk. See its [design plan](Schwarzschild_Raytracer/Schwarzschild_Raytracer_Plan.md) for the physics and implementation details.

Future additions will live as sibling project folders here, each with its own design plan (e.g. a Kerr — rotating black hole — raytracer, gravitational-wave modeling).
